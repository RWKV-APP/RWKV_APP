# Last-known signed HAP

This archive contains the last signed HAP available on the source Mac

It is provided for comparison and same-device recovery. It does not contain the private signing key and cannot sign a newly built HAP

This HAP contains both the NNRT and llama.cpp/Vulkan paths. Its archive hash and prior install history do not prove NPU-only inference. The 0.1B path must be accepted from fresh HiLog partitions on the phone

The HAP may contain a debug Profile, certificate chain, and device authorization metadata. Keep this archive private and do not publish it

On Windows, create a new debug signing identity in DevEco Studio for normal development
