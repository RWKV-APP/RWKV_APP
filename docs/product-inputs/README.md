# Product And Process Inputs

This directory is the validated historical v1.7 product and process input
archive. Do not add a new `PI-*` file for Root-routed work.

`SPEC-SYNC-ROOT-INTAKE-BOUNDARY` keeps new raw requests, Changes briefs,
planning, and delivery evidence in the private Root Harness Mission. The target
repository receives only the sanitized Delivery Contract and updates its
canonical Specification, implementation, tests, architecture, or required
durable product documentation.

Existing records continue to use the historical capture-date path
`YYYY-MM-DD/PI-YYYYMMDD-SLUG.md` and strict schema in
`docs/spec-process/templates.md`.

Existing supporting source-audit artifacts under `evidence/` preserve
historical provenance only. New Root-routed evidence is not copied here.
