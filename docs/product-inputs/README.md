# Product And Process Inputs

Store one strict `PI-*` Markdown record per independently evolving product or process assertion.

Use the capture-date path `YYYY-MM-DD/PI-YYYYMMDD-SLUG.md`, preserve the source date separately, and follow `docs/spec-process/templates.md`.

Before committing evidence, redact credentials, signed URLs, personal data, and machine-local attachment paths while preserving the requirement meaning.

Supporting source-audit artifacts may live under `docs/product-inputs/evidence/`. They preserve provenance, do not count as `PI-*` records, and cannot establish product authority without a linked strict input or observation.
