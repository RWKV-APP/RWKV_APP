# Desktop UI Redesign Authorization

Lifecycle: active

The RWKV Chat desktop UI is authorized for substantial redesign. The existing
visual composition and navigation layout are not immutable requirements.

This authorization permits design, prototyping, and later implementation work.
It does not establish a final visual contract, authorize unrelated backend
changes, prove delivery, or authorize release.

Detailed Chat-first layout, Projects, Agent UI expansion, reference products,
and visual acceptance proposals are not active product contracts. They require
separate human rulings before implementation may treat them as requirements.
