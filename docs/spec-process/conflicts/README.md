# Specification Conflicts

Unresolved records live under `current/`. Resolved records move to `resolved/` only after an explicit decision, canonical synchronization, backlinks, and resolution date.

Conflicts pause only their exact blocking scope. Use `docs/spec-process/templates.md`.

Every linked PI or OBS must share a stable assertion and affected surface with the conflict. Together, those provenance records must cover all assertions and surfaces named by the conflict.
